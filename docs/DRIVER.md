# Driver Guide

Документ описывает текущий раздел `Водитель` в Telegram-боте, web-версии и backend.

## Назначение

Раздел помогает вести автомобильный журнал:

- хранить автомобили;
- учитывать пробег;
- вести журнал заправок;
- считать расход топлива;
- учитывать ручные расходы;
- хранить документы и даты окончания;
- создавать напоминания по документам и автомобильным задачам;
- смотреть сводку по авто.

## Пользовательские Сценарии

### Авто

Поддерживается:

- создание авто из preset;
- ручное создание авто;
- редактирование;
- обновление пробега;
- удаление с подтверждением;
- просмотр карточки авто;
- расчет ближайшего ТО.

Presets сейчас включают варианты для:

- Hyundai Verna 2007 1.4 MT;
- Нива 1997 и близкие варианты;
- Ford Focus II hatchback;
- Mitsubishi Pajero Pinin;
- Lada Kalina I sedan 2008.

Preset задает стартовые справочные параметры: марка, модель, год, двигатель, коробка, ожидаемый расход и комментарий. Пользователь может уточнять реальные значения через журнал заправок.

### ТО

Для авто хранится:

- интервал ТО по километрам;
- интервал ТО по месяцам;
- пробег последнего ТО;
- дата последнего ТО.

Кнопка `ТО выполнено` обновляет точку отсчета. Следующее ТО считается по пробегу и дате.

### Заправки

Поддерживается:

- добавление заправки;
- редактирование;
- удаление с подтверждением;
- полный/неполный бак;
- история по конкретному авто;
- цена за литр;
- расход топлива;
- стоимость километра.

Расход считается устойчивее после полных баков. Неполные заправки учитываются между полными баками.

Пробег авто пересчитывается по максимуму из:

- ручного базового пробега;
- максимального пробега в оставшемся журнале заправок.

Это защищает от stale mileage после редактирования или удаления максимальной заправки.

### Расходы

Поддерживаются ручные расходы:

- ТО/ремонт;
- запчасти;
- мойка;
- страховка;
- парковка;
- штраф;
- другое.

Каждый расход может быть привязан к авто или храниться без привязки. Для расхода сохраняются название, категория, сумма, дата и комментарий.

### Документы

Поддерживаются документы:

- ОСАГО/КАСКО;
- права;
- диагностика;
- налог;
- штраф;
- другое.

Для документа можно указать дату окончания и количество дней для предварительного напоминания. DriverService синхронизирует напоминание при создании/редактировании и отменяет его при удалении документа.

### Шаблоны

Быстрые шаблоны создают списки или напоминания для типовых автомобильных задач:

- список запчастей;
- проверка перед поездкой;
- чек-лист жидкостей;
- замена масла;
- проверка жидкостей;
- мойка;
- давление в шинах.

## Web/API

User API endpoints:

```text
GET    /me/driver
GET    /me/driver/vehicle-presets
POST   /me/driver/vehicles
PATCH  /me/driver/vehicles/{vehicle_id}
POST   /me/driver/vehicles/{vehicle_id}/service-done
DELETE /me/driver/vehicles/{vehicle_id}
GET    /me/driver/vehicles/{vehicle_id}/fuel
POST   /me/driver/vehicles/{vehicle_id}/fuel
PATCH  /me/driver/fuel/{entry_id}
DELETE /me/driver/fuel/{entry_id}
GET    /me/driver/expenses
POST   /me/driver/expenses
PATCH  /me/driver/expenses/{expense_id}
DELETE /me/driver/expenses/{expense_id}
GET    /me/driver/documents
POST   /me/driver/documents
PATCH  /me/driver/documents/{document_id}
DELETE /me/driver/documents/{document_id}
```

Web-версия использует эти endpoints и не должна ходить в admin API для пользовательских данных.

- комментарий.

## Ограничения

- Расход топлива зависит от корректности отметок полного бака.
- Старые автомобили могут иметь большой разброс фактического расхода, поэтому presets являются ориентиром.
- Документы создают обычные reminder-записи, поэтому worker должен быть запущен.
- Экспорт расходов пока не реализован.
- История шин и сезонная замена пока не вынесены в отдельную сущность.
