# User Guide

Документ описывает фактическое пользовательское поведение текущей версии бота и web-версии.

## Входные точки

- Telegram bot: основное управление через кнопки главного меню.
- Mini App: `/miniapp`, вход внутри Telegram через Telegram-авторизацию.
- Web version: `/web`, вход через персональный ключ из Telegram: `Web / приложение -> Web-версия`.
- Admin UI: `/admin/ui`, вход через `ADMIN_TOKEN`. Используется только для администрирования и отладки.

Проект находится в beta/test режиме. Если включен `TESTING_NOTICE_ENABLED`, бот и web показывают предупреждение, что данные могут быть изменены или утеряны.

## Главное Меню Telegram

Основные разделы:

- `Списки`
- `Заметки`
- `Лекарства`
- `Напоминания`
- `Водитель`
- `Настройки`
- `Web / приложение`
- `Поделиться ботом`
- `Скрыть меню`
- `Помощь`

Команда `/start` открывает актуальное меню. Команда `/cancel` отменяет текущий незавершенный сценарий. Команда `/feedback` отправляет сообщение разработчику (см. «Обратная связь»).

Незаконченный сценарий (создание напоминания, заметки и т.п.) закрывается сам, если нажать кнопку главного меню, `/start` или «В меню», а также через 15 минут бездействия. Кнопки из старых сообщений не «крутятся» бесконечно: бот отвечает, что сценарий уже закрыт или запись уже сохранена.

Если написать боту обычный текст вне сценария, он предложит сделать из него напоминание или заметку.

## Списки

Что работает:

- создание личного списка;
- просмотр списка с пагинацией;
- добавление одного пункта;
- добавление нескольких пунктов пачкой;
- голосовое создание нового списка и голосовое добавление пунктов в существующий список;
- отметка пункта выполненным или невыполненным;
- интерактивное прохождение списка как личного чек-листа без изменения исходных отметок;
- редактирование пункта;
- удаление пункта с подтверждением;
- переименование списка;
- удаление списка с подтверждением;
- напоминание, привязанное к списку;
- участники общего списка;
- роли общего списка: `owner`, `editor`, `viewer`;
- токен копии списка;
- токен приглашения в общий список;
- импорт копии через `/import_list TOKEN`;
- подключение к общему списку через `/join_list TOKEN`.

Права:

- `owner` управляет списком, участниками и токенами;
- `editor` может менять содержимое списка;
- `viewer` только просматривает;
- пользователь не может управлять чужим списком без выданного доступа.

Интерактивный чек-лист:

- кнопка `Пройти чек-лист` создает личный снимок пунктов списка;
- отметки в чек-листе не меняют состояние пунктов в исходном списке;
- `viewer` общего списка может пройти личный чек-лист, но не может редактировать сам список;
- напоминание, привязанное к списку, показывает быстрый переход к списку и запуску чек-листа;
- если исходный список изменился после запуска, бот и web показывают предупреждение, но прохождение идет по сохраненной копии.

Голосовой ввод:

- в разделе `Списки` нажмите `Надиктовать`, чтобы создать новый список голосом;
- внутри конкретного списка нажмите `Голосом`, чтобы добавить пункты в этот список;
- бот сначала показывает предпросмотр распознанных пунктов;
- сохранение происходит только после подтверждения;
- для работы нужен включенный `VOICE_TRANSCRIPTION_ENABLED` и настроенный `OPENAI_API_KEY`.

## Заметки

Что работает:

- создание заметки: она сохраняется сразу после ввода названия; категорию и текст можно добавить следом или позже (кнопки «✅ Готово» и «🗑 Не сохранять»);
- просмотр списка заметок с пагинацией;
- поиск по названию и тексту заметки;
- категории заметок: рецепт, инструкция, идея, личное, другое;
- фильтр заметок по категории;
- закрепление важных заметок и быстрый фильтр `Закрепленные`;
- простое форматирование в web/Mini App: переносы строк, `# Заголовок`, `- пункт списка`;
- открытие заметки для чтения;
- напоминание, привязанное к заметке;
- редактирование названия, текста и категории;
- мягкое удаление заметки из активного списка;
- отдельный раздел в Telegram и web/Mini App.

Заметки предназначены для текста, который не нужно отмечать как выполненный: рецепты, инструкции, идеи, справочные записи. Если нужны пункты с отметками или прохождением чек-листа, используйте `Списки`.

## Лекарства

Что работает:

- создание карточки препарата: лекарство сохраняется сразу после ввода названия, остальные шаги уточняют его; «Отмена» в мастере удаляет недоделанное лекарство;
- дозировка через кнопки или текст;
- инструкция приема через кнопки или текст;
- важность: БАД, обычное, важное, критичное;
- настройка напоминаний 1, 2 или 3 раза в день;
- ручное время приема для нескольких приемов;
- отметки `принял`, `пропустил`;
- отложить прием на 15 минут;
- архивирование препарата;
- редактирование названия, дозировки, инструкции, важности и времени приема;
- скрытие кнопок приема до следующего актуального окна;
- кнопки «Принял/Пропустил» под уведомлением отмечают именно тот приём, о котором было уведомление, даже если нажать позже;
- исправление ошибочной отметки: в карточке появляется «🔄 Исправить: на самом деле принял/пропустил», а повторное нажатие другой кнопки на ту же дозу меняет отметку;
- подтверждения называют лекарство: «✅ Магний: принято»;
- **перерыв между курсами** — для лекарств, которые пьют курсами (например, раз в 3–6 месяцев):
  - карточка → «⏸ Перерыв между курсами» → 1, 2, 3, 4, 6 месяцев или своя дата;
  - затем выбрать, за сколько напомнить о скором курсе: за 3 дня, неделю, 2 недели или не напоминать;
  - во время перерыва напоминания о приёме не приходят, время приёма сохраняется;
  - в день начала курса напоминания возвращаются сами, бот присылает сообщение;
  - «▶️ Возобновить курс сейчас» и «📅 Изменить срок перерыва» доступны в карточке;
- **сводка за неделю**: по воскресеньям в 19:00 (по вашему времени) — сколько приёмов принято, пропущено и без отметки; также кнопка «📊 Сводка за неделю» в списке лекарств; отключается там же.

Важно: бот помогает вести учет и напоминать, но не назначает лечение и не заменяет врача.

## Напоминания

Что работает:

- создание через текст;
- быстрый выбор даты: сегодня, завтра, послезавтра, через неделю;
- быстрый выбор времени и ручной ввод;
- фразы вида `завтра 10`, `28 мая 15`, `послезавтра вечером`, `через 2 часа`;
- дата и время прямо в тексте: «завтра в 10 позвонить маме», «в пн в 8:15 планёрка», «через полчаса чай» — бот сразу ставит время;
- напоминание сохраняется в момент выбора времени; дальше можно настроить уведомления и повтор или нажать «✅ Готово»;
- выбор уведомлений: в выбранное время, за 30 минут, за 1 час, за сутки или несколько раз до события;
- повторы: без повтора, каждый день, каждую неделю, каждый месяц;
- просмотр активных и завершенных;
- привязка напоминания к списку или заметке без смешивания этих сущностей;
- выполнение, отмена, удаление;
- редактирование текста, времени и повтора;
- кнопки под пришедшим напоминанием: «✅ Сделано», «⏰ 15 мин», «⏰ 1 час», «📅 Завтра» (отложить создаёт ещё одно напоминание, повторяющаяся серия при этом продолжается);
- повторяющиеся напоминания продолжаются после «Выполнено» и после неудачной доставки; ежемесячные на 29–31 число не сдвигаются на другие дни;
- при смене часового пояса напоминания остаются на тех же часах по местному времени.

Время события хранится в UTC, а пользователю показывается в его часовом поясе. Доставка хранится отдельными строками уведомлений, поэтому одно напоминание может прислать несколько сообщений до события и одно финальное сообщение в выбранное время.

## Водитель

Что работает:

- список автомобилей;
- добавление авто вручную;
- предвыбор популярных авто из presets;
- марка, модель, год, двигатель, коробка, ожидаемый расход;
- текущий пробег;
- интервалы ТО по пробегу и месяцам;
- отметка ТО выполненным;
- журнал заправок;
- полный и неполный бак;
- расчет цены за литр;
- расчет расхода после полных баков;
- ручные расходы: ремонт, ТО, мойка, страховка, парковка, штрафы, прочее;
- документы: ОСАГО/КАСКО, права, диагностика, налог, штраф, другое;
- напоминания по документам;
- сводка и статистика;
- быстрые шаблоны списков и авто-напоминаний.

Пробег авто пересчитывается по ручному базовому пробегу и максимальному пробегу в журнале заправок. После редактирования или удаления максимальной заправки пробег не должен оставаться завышенным.

## Настройки

Что работает:

- часовой пояс;
- статистика пользователя;
- статистика других пользователей для администратора;
- текущий план/подписка;
- web-ключ;
- информация о боте;
- история версий;
- служебный статус для администратора;
- `🌅 План на день` — по желанию: каждое утро в 08:00 (по вашему времени) одно сообщение с напоминаниями на сегодня и временем приёма лекарств; в пустой день сообщения нет; есть кнопка «Показать план на сегодня»;
- `💬 Обратная связь`;
- для администратора в `О боте`: журнал ошибок, обращения пользователей и оповещения (см. [Руководство администратора](ADMIN.md)).

Обычные пользователи видят только свои данные. Административная статистика агрегирует активность без хранения текста пользовательских сообщений.

## Web Version

В Telegram пункт `Web / приложение` показывает выбор:

- `Открыть приложение` - запускает Mini App внутри Telegram, если настроен публичный HTTPS `WEB_PUBLIC_URL`.
- `Web-версия` - выдает персональный ключ и ссылку для обычной web-версии `/web`.

Адрес локально:

```text
http://127.0.0.1:8000/web
```

Вход:

1. В Telegram открыть `Web / приложение -> Web-версия`.
2. Получить персональный ключ.
3. Открыть `/web`.
4. Вставить ключ или перейти по прямой ссылке, если задан `WEB_PUBLIC_URL`.

Web-версия покрывает:

- сводку;
- списки и общие списки;
- заметки;
- напоминания;
- лекарства;
- водительский журнал;
- настройки.

В лекарствах web-версии доступны перерыв между курсами (поставить, изменить, возобновить) и исправление отметки приёма. На главной странице есть форма обратной связи.

Администрирование вынесено в отдельный `/admin/ui` и в раздел «Админ-панель», который виден только администратору с admin-токеном.

## Обратная Связь

- В Telegram: `/feedback` или `Настройки → 💬 Обратная связь`; в web — форма на главной.
- Выберите тип (ошибка, идея, другое) и напишите одно сообщение; к ошибке можно приложить скриншот.
- Сообщение получает только разработчик; ответ придёт от бота в этот же чат.
- Не больше 10 сообщений в час от одного человека.

## Что Делать При Проблемах

- Если кнопки Telegram не обновились, отправить `/start`.
- Если база новая, выполнить `python -B -m src.main init-db`.
- Если web не открывается, проверить, что запущен `api`.
- Если напоминания не приходят, проверить, что запущен `worker`.
- Если время отображается неверно, проверить `Настройки -> Часовой пояс`.
